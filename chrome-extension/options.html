ssf factories

Each factory is the capability URL ssf-server logs, such as http://127.0.0.1:8787/<secret>/. Keep it private: it grants access to repository details and session summaries. The badge on github.com reads these factories.

Chrome asks permission for each factory's address the first time; that permission is what lets the extension read the factory without allowing it anywhere else. Use Allow beside a factory to ask again after a refusal.
